# Сворачиваемое описание на странице товара

## Цель
Описание товара на `/product/$id` (и дубль на `/shop/$slug`) часто слишком длинное и перегружает страницу. Нужно сделать текст сворачиваемым: по умолчанию показывается ограниченный объём, по клику — разворачивается полностью.

## Текущее состояние (подтверждено чтением)
- `src/routes/product.$id.tsx:393` — описание рендерится как один `<p className="mt-6 whitespace-pre-line text-base leading-relaxed text-foreground/85">{description}</p>`.
- `src/routes/shop.$slug.tsx:206-208` — аналогичный блок `<p ...>{description}</p>`.
- В обоих файлах уже импортированы `lucide-react` и фреймворк; для иконки раскрытия используем `ChevronDown` из lucide-react.

## План изменений

### 1. Новый компонент `src/components/expandable-text.tsx`
- Props: `text`, `maxHeight` (по умолчанию ~6 строк / ~144px), `className`.
- Логика:
  - Состояние `expanded` (по умолчанию `false`).
  - Обёрнут в `<div>` с `overflow-hidden` и `transition-[max-height]`.
  - В свёрнутом виде применяется `max-h-[...]` + плавный градиент-«затухание» снизу (`bg-gradient-to-t from-card/cream`) чтобы показать, что текст обрезан.
  - Текст рендерится с `whitespace-pre-line` (сохраняем переносы из БД).
  - Кнопка-переключатель «Mehr anzeigen» / «Weniger anzeigen» (i18n через `useT`); иконка `ChevronDown` вращается при раскрытии.
  - Кнопка показывается только если реальная высота текста превышает порог (через `useRef` + `useEffect` замер `scrollHeight`); для коротких описаний блок ведёт себя как обычный `<p>` без кнопки.
- Безопасность гидратации: серверный рендер всегда отдаёт свёрнутый вариант (единый), замер высоты происходит только в `useEffect` после монтирования — без рассинхрона с SSR.

### 2. Подключение на `/product/$id`
- Заменить `<p ...>{description}</p>` на `<ExpandableText text={description} />` (`src/routes/product.$id.tsx:393`).

### 3. Подключение на `/shop/$slug`
- Заменить `<p ...>{description}</p>` на `<ExpandableText text={description} />` (`src/routes/shop.$slug.tsx:206-208`).

### 4. i18n
- Добавить ключи в `src/i18n/de.ts` и `src/i18n/en.ts`: `product.showMore`, `product.showLess` (DE: «Mehr anzeigen» / «Weniger anzeigen»; EN: «Show more» / «Show less»).

## Поведение
- Короткие описания (меньше порога) — показываются целиком, без кнопки.
- Длинные — обрезаются с затуханием, кнопка разворачивает весь текст анимированно; повторный клик сворачивает обратно.
- Стиль и отступы совпадают с текущим дизайном (`text-foreground/85`, `whitespace-pre-line`).

## Проверка
- `bunx tsgo --noEmit -p tsconfig.json` — без ошибок типов.
- Проверить в превью карточку/PDP с длинным описанием (кнопка появляется, раскрывает/сворачивает) и с коротким (кнопки нет).
- Проверить `/shop/$slug`, если маршрут активен.

## Объём изменений
Только фронтенд/презентационный код: 1 новый компонент, 2 правки импорта/использования, 2 i18n-ключа. Бизнес-логика, ценообразование и БД не затрагиваются.
