# Поиск товаров на сайте

## Что появится

**1. Поиск в шапке (на всех страницах)**
- На компьютере: поле с иконкой лупы между меню и переключателем DE/EN.
- На телефоне: только иконка лупы, по нажатию под шапкой раскрывается поле ввода.
- Кнопка «×» очищает поле.
- Во время ввода (пауза ~300 мс) выпадает до 5 подходящих товаров: миниатюра, название, цена (с учётом текущей скидки, как в карточках).
- Клик по подсказке открывает страницу товара.
- Enter или клик по лупе ведёт на `/shop?search=запрос`.
- Esc закрывает подсказки; стрелки вверх/вниз выбирают подсказку; клик вне поля тоже закрывает.

**2. Поиск на странице Shop**
- Поле поиска над сеткой, в строке со счётчиком товаров и сортировкой.
- Работает вместе с фильтрами (повод, материал, формат) и сортировкой — ничего не сбрасывает.
- Значение хранится в адресе (`?search=`), поэтому ссылка из шапки сразу показывает результаты.
- Счётчик: «N Produkte» / при поиске «N Treffer für „…“».
- Если ничего не найдено: «Keine Ergebnisse für „…“» и кнопка «Suche zurücksetzen» (тексты на немецком и английском, как весь сайт).

**3. Логика поиска**
- Ищем по названию (DE и EN), описанию и категории/поводу, без учёта регистра.
- Пустой запрос — показываются все товары.

## Дизайн
Те же цвета (walnut/brass/cream), скругления rounded-full, шрифты и отступы. Используются существующие компоненты Input и Button. У полей есть aria-label, работает фокус с клавиатуры. Остальная логика и вид сайта не меняются.

## Технические детали
- `src/lib/product-search.ts`: `matchesSearch(product, query)` — нормализация (lowercase, trim), поиск по name_de/en, description_de/en, category, occasion + переведённый повод.
- `src/hooks/use-debounce.ts`: простой debounce-хук (300 мс).
- `src/components/header-search.tsx`: использует общий запрос `["products"]` через `useQuery` (без блокировки шапки), цены через `catalogFromPrice` + существующие query options; навигация через `Link`/`useNavigate` на `/product/$id` и `/shop` с `search`.
- `src/components/header.tsx`: вставка desktop-поля и мобильной иконки с раскрывающейся панелью.
- `src/routes/shop.index.tsx`: добавить `search: z.string().optional()` в схему, локальное состояние поля с debounce, синхронизация в URL через `navigate({ search: prev => ({...prev, search}) , replace: true })`, фильтр в существующем `useMemo`, пустое состояние с кнопкой сброса.
- Новые ключи в `src/i18n/de.ts` и `src/i18n/en.ts` (`search.*`).
