# План: ссылка на заказанный товар в заказах админ-панели

## Что уже выяснено
- В каждой позиции заказа (`orders.items[]`) уже сохраняется `productId` (обязательное поле при чекауте) и опциональный `slug` — данные есть, миграция не нужна.
- Страница товара на сайте: `/product/$id` (`src/routes/product.$id.tsx`).
- Карточка позиции заказа — `ItemCard` в `src/routes/admin/orders.tsx`; сейчас название товара выводится простым текстом.

## Что делаем
В `ItemCard` (`src/routes/admin/orders.tsx`) сделать название товара кликабельной ссылкой:
- Если у позиции есть `productId` — название становится `<Link to="/product/$id" params={{ id: item.productId }}>`, открывается витрина сайта (то, что видел покупатель). Открывать в новой вкладке (`target="_blank"`), чтобы не терять заказ.
- Стиль — как у существующих ссылок в админке: цвет `text-walnut`, подчёркивание, иконка `ExternalLink` (уже импортирована) рядом с ценой или после названия.
- Если `productId` по какой-то причине отсутствует (старые заказы) — название остаётся обычным текстом, ничего не ломается.

Изменения только в одном файле `src/routes/admin/orders.tsx`. База данных и серверная логика не затрагиваются.

## Проверка
- Открыть /admin/orders, раскрыть заказ, нажать на название товара — открывается страница товара на витрине.
- Сборка без ошибок.
