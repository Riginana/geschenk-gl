# Язык календаря в поле Datum

- Привязать календарь в блоке Personalisierung к выбранному языку сайта: немецкий при DE, английский при EN.
- Убрать зависимость подписей месяцев от языка устройства: сокращения месяцев, дни недели и подписи календаря должны соответствовать DE/EN и обновляться при переключении языка.
- Сохранить нынешний формат вводимой даты и поведение выбора даты без других изменений страницы товара.
- Проверить календарь на странице товара в обоих языках, включая выпадающий список месяцев.

## Технические детали

Календарь использует `react-day-picker`: передать ему соответствующую локаль `date-fns` из текущего языкового контекста. В общем компоненте календаря заменить `toLocaleString("default", ...)` для выпадающего списка месяцев на форматирование по переданной локали (либо убрать переопределение в пользу локализованного форматтера библиотеки), чтобы язык системы не влиял на подписи.
