# Аудит и план массового импорта 36 товаров

## Ответы аудита

**1. Где хранятся товары.** В таблице `products`. Без каких полей товар не создать:
- `slug` (уникальный адрес),
- `name_de`, `name_en`,
- `description_de`, `description_en`,
- `base_price_cents`,
- `occasion` (повод).

Остальные поля заполняются сами:
- `category` = other, `material` = karton, `discount_percent` = 30, `in_stock` = да;
- `is_active` по умолчанию «да». При импорте ставим «нет», чтобы товары не публиковались.

Для рамок важно поле `frame_material` (Papier / Holz / HDF): от него зависит, какая таблица цен применяется.

**2. Несколько фото.** Хранятся в таблице `product_images`: одна строка на фото.
- В строке: ссылка, роль (`hero` = главное или `gallery`), порядок (`sort_order`) и подпись (alt).
- Главное фото задаётся полем `products.hero_image`. Если оно пустое, магазин берёт фото с ролью hero, а если такого нет — первое по порядку.
- Сейчас в базе 135 главных фото и 947 фото галереи.

**3. Видео.** Одно видео на товар, его ссылка лежит в поле `products.product_video_url`. Загрузка видео уже работает в админке: MP4/WebM до 100 МБ, в то же хранилище. На странице товара видео показывается в галерее.

**4. Хранилище и лимиты.**
- Всё лежит в одной публичной папке хранилища `product-images`, в подпапке на каждый товар.
- Сама папка лимита не задаёт. Админка проверяет размер сама: фото JPG/PNG/WebP до 20 МБ, видео до 100 МБ.
- Есть общий лимит хранилища на один файл, и я его ещё не проверял. Если видео тяжелее 50 МБ, перед импортом нужно проверить или поднять этот лимит.

**5. Безопасный массовый импорт.** Возможен. Механизм загрузки уже есть: админка выдаёт одноразовую ссылку, и браузер загружает файл прямо в хранилище. Импорт будет повторять это для каждого файла. Доступ только для администратора, вход проверяется на сервере.

**6. Предпросмотр, ошибки, дубликаты.**
- **До записи в базу** — таблица предпросмотра: по каждому товару видно название, цену, категорию, число фото и наличие видео. Строки с ошибками отмечены красным.
- **Что проверяется:**
  - обязательные поля;
  - цена — число;
  - категория из списка;
  - Papier/Holz/HDF для рамок;
  - все файлы из таблицы есть в архиве;
  - формат и размер файлов;
  - 1 главное фото;
  - описание на DE (если EN пустое, берётся DE).
- **Защита от дубликатов:**
  - в каждой строке ID листинга Etsy (или артикул);
  - перед созданием проверяем, нет ли товара с таким же адресом или тем же Etsy-ID (Etsy-ID хранится в поле `tags`, без изменения структуры базы);
  - дубликат помечается и пропускается;
  - если запустить импорт повторно, уже созданные товары не задваиваются.

**7. Временная страница в админке.** Да. Новая страница `/admin/import` внутри существующей админки, под тем же входом. Дизайн и логика магазина не меняются. После импорта страницу можно убрать.

## Рекомендуемый способ: ZIP + CSV через /admin/import

**Формат, который вы готовите:**

```text
import.zip
  products.csv
  etsy-123456/   01.jpg ... 08.jpg  video.mp4
  etsy-123457/   ...
```

Колонки `products.csv`:
- `etsy_id`, `folder`, `name_de`, `name_en`;
- `description_de`, `description_en`;
- `category`, `occasion`, `frame_material`;
- `base_price_eur`, `discount_percent`;
- `hero_file` — необязательно, иначе главным станет первый файл.

Порядок фото задаётся именами файлов (01, 02, …). Я подготовлю шаблон CSV с примером строки.

**Этапы:**
1. **Загрузка ZIP.** Архив распаковывается прямо в браузере, на сервер он не отправляется. CSV читается, по нему строится таблица предпросмотра с проверками.
2. **Проверка.** Ошибки и дубликаты видны сразу. Кнопка «Импорт» доступна только если ошибок нет (дубликаты пропускаются).
3. **Импорт по одному товару:**
   - создаётся черновик (скрыт из магазина);
   - загружаются фото и видео;
   - записываются ссылки и порядок фото.

   Прогресс-бар показывает каждый товар. Если загрузка прервалась, частично созданный черновик удаляется вместе с файлами, а повторный запуск продолжит с того же места.
4. **Отчёт.** Список созданных черновиков со ссылками на их страницы в админке.
5. **Проверка и публикация вручную.** Вы просматриваете черновики и включаете их выбранными товарами через уже существующую массовую кнопку «Aktivieren». Автоматически ничего не публикуется.

**Описания с Etsy:** их нужно один раз вставить в CSV. Подключиться к Etsy напрямую без вашего доступа к Etsy API нельзя.

## Технические детали
- Новый маршрут `src/routes/admin/import.tsx` (под существующим админ-гардом в `admin/route.tsx`) и пункт «Import» в боковом меню.
- Распаковка ZIP в браузере (`jszip`), разбор CSV (`papaparse`), проверка через zod.
- Серверные функции в `src/lib/admin-import.functions.ts` (с `requireSupabaseAuth` и `requireAdmin`):
  - `adminCheckImportDuplicates(slugs, etsyIds)`;
  - `adminCreateImportDraft(...)` — вставка с `is_active=false`, `tags=["etsy:<id>"]`, `frame_material`;
  - `adminFinalizeImportedProduct` — массовая вставка в `product_images` и запись `hero_image` / `product_video_url`;
  - `adminRollbackImportDraft`.
- Загрузка файлов через существующую `adminCreateUploadUrl` и `uploadToSignedUrl`, по 3 файла параллельно.
- Без изменений схемы базы, без изменений страниц магазина.
- Перед запуском проверить общий лимит хранилища на файл и при необходимости поднять его до 100 МБ.
